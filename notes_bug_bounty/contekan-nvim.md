### TIDAK MENGGUNAKAN ARROW !

sebelum mencoba lebih banyak keymaps di neovim saya sarakan pelajari shortcut ini, shortcut ini sangat membantu saya dalam meningkatkan kecepatan ngoding
dalam mode visual

` h j k l ` - untuk ke kiri, bawah, atas, kanan <br><br> 
<T> mungkin kamu lebih sering pakai arrow `up,down,left,right` bukanya ~arrow~ jelek tapi jika kamu ingin ngoding makin gacor kamu wajib migrasi dari arrow ke `h,j,k,l` mulai dari sekarang aku yakin kamu ***bisa ngoding lebih cepat dari sebelumnya***
saya dan teman-teman komunitas saya sudah membuktikanya dan efeknya saya lebih cepat hingga 3x lipat saat menggunakan shortcut `h,j,k,l`.

kamu bisa mencoba main game ini untuk membiasakan diri menggunakan shortcut diatas
